# סקרן

**מה תרצו ללמוד היום?** כותבים נושא, בוחרים 5, 10, 15 או 30 דקות, ומקבלים קורס אישי וקצר, בלי פרסומות ובלי הסחות דעת.

כל קורס בנוי כרשת סביב **הפיד**, העיקר שצריך לדעת על הנושא. מסביבו:

- **סרטונים** קיימים מיוטיוב, עם תמונה ממוזערת ונגן גדול שנפתח מעל הדף
- **תמונות** אמיתיות מוויקישיתוף, עם שם הצלם והרישיון, ו**איורים** שנוצרים לכל קורס, מפוזרים בין חלקי הרשת
- **פודקאסט**: פרקים קיימים שאפשר לשמוע בדף, טיוטה לפרק אישי, ופודקאסטים מומלצים שנבדק שהם קיימים
- **שיר** קיים שקשור לנושא, עם קרדיט, עטיפה וקטע האזנה, אחרי בדיקה בקטלוג של Apple
- חידה, בדיחה, עובדה מפתיעה, מידע פיקנטי, מבחן עצמי, מקורות להעמקה והערות אישיות

כשאין סרטון או פודקאסט מתאים, המשבצת מציגה "התוכן יווצר בקרוב...". יצירת וידאו ופודקאסט בקולות אמיתיים היא השלב הבא.

## איך זה עובד

- `public/`: הדף עצמו (HTML, CSS ו-JavaScript רגילים, בלי ספריות).
- `api/`: פונקציות שרת קטנות ב-Vercel. רק הן מחזיקות את המפתחות.
  - `course.js` שולח את הנושא ל-Claude ומזרים את הקורס לדף בשלושה חלקים במקביל: הפיד והמבחן, המשבצות הקטנות, והאיורים.
  - `videos.js`, `photos.js`, `music.js`, `podcasts.js` מחפשים ביוטיוב, בוויקיפדיה ובוויקישיתוף, וב-Apple.
  - `status.js` אומר לדף מה מוגדר בשרת, בלי לחשוף מפתחות.
- `lib/`: הפרומפטים, בדיקת הקלט, מגבלת קצב, וההמרה של תשובות השירותים.
- `test/`: בדיקות אוטומטיות (`npm test`), עם תחליפים מקומיים לכל השירותים החיצוניים.

הדף שולח לשרת רק את הנושא, הזמן והקהל. הפרומפטים נבנים בשרת.

## העלאה לאוויר ב-Vercel

1. נכנסים ל-[vercel.com](https://vercel.com) ונרשמים עם חשבון GitHub (התוכנית החינמית מספיקה לשלב הזה).
2. **Add New → Project**, ובוחרים את המאגר `sakran`. אין צורך לשנות הגדרות בנייה: הקובץ `vercel.json` כבר מגדיר הכול.
3. לפני **Deploy** פותחים את **Environment Variables** ומוסיפים:

| משתנה | חובה? | מה זה |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | כן | מפתח ל-Claude. יוצרים ב-[Claude Console](https://platform.claude.com), תחת Settings → API keys. |
| `CLAUDE_MODEL` | כן | מזהה המודל של Claude שבו האפליקציה תשתמש. הרשימה ב[עמוד המודלים](https://platform.claude.com/docs/en/about-claude/models/overview). |
| `YOUTUBE_API_KEY` | מומלץ | בלעדיו מוצגים קישורי חיפוש במקום סרטונים. ראו למטה. |
| `ACCESS_CODE` | לא | אם מגדירים, רק מי שיודע את הקוד יכול לבנות קורסים חדשים. טוב לתקופת הרצה סגורה. הקורס המוכן פתוח לכולם. |
| `RATE_LIMIT_PER_10_MIN` | לא | כמה בקשות מותר לכל גולש ב-10 דקות. כל קורס הוא 3 בקשות. ברירת המחדל 30. |
| `CLAUDE_FALLBACKS` | לא | `off` מכבה את הניסיון החוזר על מודל חלופי כש-Claude מסרב לבקשה מטעמי בטיחות. דלוק כברירת מחדל. |

4. **Deploy**. אחרי דקה בערך האתר באוויר בכתובת ש-Vercel נותן, ואפשר לחבר אליו דומיין.

שינוי במשתנים נכנס לתוקף אחרי פריסה מחדש (**Deployments → Redeploy**).

### עלויות ובטיחות

- **Claude** מחויב לפי שימוש, והמחיר תלוי במודל שבוחרים. כדאי מאוד להגדיר תקרת הוצאה חודשית ב-Console, תחת Settings → Limits.
- מגבלת הקצב נספרת בכל שרת של Vercel בנפרד, ולכן היא מאטה משתמש כבד אבל לא חוסמת לגמרי. תקרת ההוצאה וקוד הגישה הם ההגנה העיקרית.
- כש-Claude מסרב לבקשה מטעמי בטיחות, השרת מבקש מה-API לנסות שוב על מודל חלופי שמומלץ לאותו מקרה. אם המודל שבחרתם לא תומך בזה, השרת מזהה את זה בבקשה הראשונה ומפסיק לבקש.

### מפתח ל-YouTube

1. ב-[Google Cloud Console](https://console.cloud.google.com) יוצרים פרויקט.
2. **APIs & Services → Library**, מחפשים **YouTube Data API v3** ומפעילים.
3. **Credentials → Create credentials → API key**. כדאי להגביל את המפתח ל-YouTube Data API v3 בלבד.

המכסה החינמית היא 10,000 יחידות ביום. כל קורס חדש עולה כ-200 יחידות (שני חיפושים), כלומר כ-50 קורסים חדשים ביום. תשובות נשמרות במטמון של Vercel ליום, כך שנושא שכבר נלמד לא עולה שוב. אפשר לבקש מגוגל להגדיל את המכסה.

## פיתוח מקומי

```sh
npm install
cp .env.example .env   # וממלאים את המפתחות
npm run dev            # http://localhost:3000
npm test
```

## פרטיות

- הנושא שכותבים נשלח ל-Claude (Anthropic), ושם הנושא נשלח לחיפוש ב-YouTube, בוויקיפדיה ובוויקישיתוף, וב-Apple.
- אין מסד נתונים ואין חשבונות משתמשים. הקורס האחרון וההערות נשמרים רק בדפדפן של הלומד.
- התוכן נכתב בעזרת בינה מלאכותית ועלול לכלול טעויות, והדף אומר את זה ללומדים.
